# 墨边 · Marginalia

本地沉浸式阅读与笔记应用。正文居中，笔记落在两侧页边；Windows / macOS 独立安装，后续用同一套代码打包 Android / iOS。

## 功能（v0.1）

- **格式**：EPUB（EPUB 2/3，含目录、图片、内部链接）、PDF（懒渲染 + 文本层，CJK cMap 离线内置）、Markdown、TXT（自动识别 GBK、按「第X章」切章）、本地 HTML（Readability 提取正文）
- **标注**：10 种配色 × 12 种样式（高亮、马克笔｜下划线、双底线、波浪线、虚线、点线｜着重号、框选、圈注、侧线、删除线），SVG 覆盖层绘制，不改动原文 DOM
- **网页剪藏**：书架页「保存网页」或直接 Ctrl+V 粘贴网址；浏览器书签工具「存到墨边」（`marginalia://clip?url=…`）一键保存。抓取后用 Readability 提取正文，图片内嵌为离线快照；适配微信公众号（懒加载图片、防盗链、作者与发布时间）、GBK 老站点；同一网址自动去重。剪藏文章在书架与笔记中心归入「文章」
- **订阅**（首页「探索」）：添加常看的博客/网站（自动发现 RSS / Atom / JSON Feed，含未声明的 `/feed`）或公众号「合集」链接，支持一次粘贴多个、导入 OPML。新文章按时间汇成收件箱，显示标题与首段（自动跳过编者按、署名、募捐说明等套话，同源重复段落自动识别）；「保存精读」静默存入书架，可忽略 / 已读 / 恢复。每个来源可标注多个「阅读兴趣」（如 基督教、AI、法律、控制论），在侧栏按兴趣筛选文章；订阅页顶部是「添加订阅」「添加网文」两个主按钮；手动保存的网页文章归入「手动添加」来源。启动时及每 30 分钟自动更新（条件请求，失败退避）；订阅源里的失效外链会自动改用订阅源自身域名；未保存条目保留 90 天
- **笔记与多级标签**：笔记正文里写 `#读书/方法`（Flomo 风格），输入 `#` 时补全全局标签；标签跨书通用，筛选父标签自动包含子标签
- **书架显示方式**：「封面」或「列表」可切换（记住你的选择）。封面按文档类型统一配色并在右上角标注类型图标（PDF 梅紫、EPUB 琥珀金、Markdown 蓝、TXT 石墨灰、网页青绿）；列表模式是紧凑的行卡片，分栏数量随窗口宽度自动增减（每栏至少约 340px），文章很多时更易浏览
- **书架分类**：书籍 / 文章都可标注多个「阅读兴趣」（卡片上的标签图标），与订阅共用同一套兴趣词；从订阅保存的文章自动继承订阅源的兴趣。书架顶部可按兴趣筛选（多选取并集、「未分类」）或「按兴趣分组」
- **笔记配图**：随手记、原文旁的笔记和笔记中心里的就地编辑都支持图片：直接 Ctrl+V 粘贴截图、拖入图片文件，或点图片按钮选择本地文件（每条最多 9 张，过大的自动缩到 2000px 以内）。图片以文件形式存在数据目录的 images/ 下，点缩略图可放大查看
- **书架批量操作**：书架顶部有搜索框（标题、作者、站点、附注、兴趣）和「选择」按钮。进入选择模式后单击勾选、Shift+单击选一段、「全选当前结果」按当前筛选和搜索全选；底部操作条可一次给所选项加 / 去掉阅读兴趣标签、批量设为想读 / 在读 / 读完。Esc 退出
- **区域批注（框选）**：PDF 里没有可选文字的页（扫描件）直接拖动鼠标框选即可；有文字的页面按住 Alt 拖，或点顶栏「框选」按钮后拖。EPUB / 网页文章 / Markdown 里的图片（含 SVG 插图、封面、带链接的图）上直接拖也能框选图片的一部分。框的颜色 / 样式可选，可写笔记和标签；框住的区域会截成图片作为引用，显示在笔记卡片、笔记页、每日回顾里，导出 Markdown 时以 `![[图片]]` 嵌入并注明页码。框按页面比例保存，缩放窗口 / 界面时始终贴住原位置
- **笔记关系与关系图**：笔记之间可以建立「关系」，每条关系带一句文字说明（支持 / 反驳 / 举例 / 出处 / 延伸，或随便写），是多对多的网：一条笔记可连接任意多条笔记，也可被任意多条连接，同一对笔记之间还能有多条不同的关系。
  - **建立**：笔记卡片底部的链条图标 →「连接笔记」（可搜索并多选，一次连接多条）或「新建相关笔记」（写一条新笔记并自动与来源笔记连接）；笔记页批量选择多条后点「新建相关笔记」，新笔记与每一条所选笔记各连一条
  - **编辑**：笔记下方的「关系」列表里，点关系文字就地修改，× 删除连接（不会删除笔记），点对方摘要跳转到它
  - **关系图**（笔记中心侧栏「关系图」）：笔记是卡片，关系是带文字的连线。拖卡片移动（位置会记住）；建立关系有两种拖法：拖卡片右侧的橙色圆点到另一张卡片，或直接把一张卡片拖到另一张卡片上方（对方卡片会高亮并提示「松手建立关系」，松手后卡片回到原位并让你填写关系）；卡片默认能显示 45 个字（每行 15 字 × 3 行），拖右边、下边或右下角可调整大小，最小可缩成小圆点（右键也可「缩成小圆点 / 恢复默认大小」），大小会记住；每条连线的起点和终点都能指定从卡片的上 / 下 / 左 / 右哪个点出入：点连线上的文字，两张卡片上会出现四个小圆点：线现在用的那一端是个大圆点，可以直接拖到卡片的另一个点上松手（拖动时线实时预览、目标点高亮，松手自动吸附到最近的点），也可以直接点小圆点；点一下大圆点是固定 / 取消固定，「全部自动」一键还原；选中一条线后按 `Delete` 键即可删除这条线（不会删除笔记）；点连线上的文字修改或删除（同一处还能给这条线换 11 种颜色、选实线 / 虚线 / 点线；连线样式在工具栏切换（默认流线）：弧线、流线（思维导图式 S 形曲线，从卡片两侧出线）、圆角折线、直线；画线时会自动避开其他连线和无关的卡片，同一对笔记的多条关系自动分开；工具栏「整理」按「尽量少交叉」重排所有卡片）、点卡片查看详情和它的全部关系、右键卡片新建相关笔记 / 只看它的邻居（1–3 度），可按标签筛选，滚轮缩放、拖空白处平移。窗口较窄时自动变成列表。点工具栏右上角「全屏」（或按 `F`）进入全屏：关系图铺满整个窗口，应用窗口本身也进入系统全屏，选中笔记的详情面板浮在画布上并可收起；`Esc` 退出
  - Markdown 导出与备份会在每条笔记下追加「相关笔记」清单；删除笔记时它的连接自动清除
- **笔记格式**：所有写笔记的地方都支持轻量格式：粗体 `**文字**`（Ctrl+B）、斜体 `*文字*`（Ctrl+I）、下划线 `<u>文字</u>`（Ctrl+U）、删除线 `~~文字~~`（Ctrl+Shift+X）、`- ` 项目符号与 `1. ` 编号列表（回车自动续行，空项回车结束列表）。编辑区工具栏有对应按钮；格式以普通文字保存，搜索、标签、Markdown 导出与备份都不受影响，导出后在 Obsidian 里同样生效
- **随手记**：笔记中心顶部是 Flomo 风格的写作框，记与书籍 / 文章无关的普通想法；行内输入 `#标签/子标签`（跟随光标的候选菜单）、`Ctrl+Enter` 发送、草稿自动保存，筛选某标签时自动预填。左侧栏顶部有统计与热力图（一天一个方块，点击按日筛选，统计所有笔记）。搜索语法 `类型:随手记`。
- **整体笔记**：除了针对选中文字的笔记，每本书 / 每篇文章还能写多条「整体笔记」（带标签、按时间排列）。阅读页右侧页边顶部有固定卡片，顶栏也有入口；面板里同时可以给书打 1–5 星、标记「想读 / 在读 / 读完」（未标记时按阅读进度自动判断）。书架封面显示整体笔记标记、状态与星级，可按状态筛选；笔记中心可按「阅读全局笔记 / 原文摘录 / 批注笔记」筛选（搜索语法 `类型:整体`），每日回顾、导出同样包含
- **笔记中心**（首页「笔记」）：标签树（置顶 / 改名 / 移动 / 合并 / 移除）、按书籍或文章筛选、颜色与「只看有想法」筛选、全文搜索、时间线或按书分组、就地编辑、一键回到原文；书内「本书笔记」面板复用同一套组件
  - **组合搜索**：`#标签` · `书:标题` · `色:琥珀` · `样式:波浪线` · `有想法`，可与关键词任意组合
  - **批量操作**：选择模式下批量加标签 / 移除标签 / 改颜色 / 导出 / 删除
  - **导出**：当前筛选结果或所选笔记导出为 Markdown（标签原样保留，Obsidian 可识别多级标签）
  - **收藏的筛选**：☆ 保存当前筛选（含来源），侧栏一键恢复
  - **每日回顾**：每天从过往笔记中稳定挑选 5 条（可「换一批」、可只看有想法的）
- **页边笔记**：按可用宽度自动切换三档
  - ≥ ~1050px：**双侧**（自动平衡分配，可逐条固定到某一侧；只有写了想法或标签的笔记才占页边）
  - ≥ ~800px：**单侧**
  - 更窄：**收起**为页边色条，点开从底部抽屉编辑（手机竖屏）
  - 另有「沉浸」模式隐藏全部页边
  - 卡片对齐原文所在行，自动避让，激活卡片有连接线
- **锚点**：W3C Web Annotation 思路，字符偏移 + 原文引用（前后文）双重定位，改字号/改版后仍能找回
- **阅读体验**：纸张 / 素白 / 夜读三主题，宋体 / 楷体 / 黑体，字号行距可调（Ctrl +/-），顶栏随滚动自动隐藏，记忆阅读位置（与字号无关）
- **桌面集成**：系统文件关联（双击 .epub/.pdf/.md/.txt 打开）、拖拽导入、单实例（再次打开文件会交给已运行的窗口）、导出笔记为 Markdown

## 开发

前置：Node 20+、Rust（stable）、Windows 需 WebView2（Win11 自带）。

```bash
npm install
npm run tauri dev      # 桌面应用开发模式（热更新）
npm run dev            # 仅前端，在浏览器里调 UI（书只存在内存中）
npm run typecheck
npm run tauri build    # 生成安装包 → src-tauri/target/release/bundle/
```

Windows 产物：`bundle/nsis/*-setup.exe`（推荐分发）与 `bundle/msi/*.msi`。
macOS 需在 Mac 上执行 `npm run tauri build`，并配置 Apple 开发者签名与公证。

数据存放在系统应用数据目录（Windows：新安装为 `%APPDATA%\Marginalia\`；早期版本装过的电脑仍沿用 `%APPDATA%\com.shengmin.reader\`）：

- `books/<sha256>.<ext>`：导入的原文件副本
- 书库信息（每本书的标题、进度、评分、状态、兴趣等）在 `reader.db` 的 `books` 表里，一本书一行。旧版本的 `library.json` 会在首次启动时自动导入，原文件改名为 `library.json.migrated-<时间>.bak` 保留
- `saved_filters.json`：收藏的筛选
- `reader.db`：SQLite 笔记库（`notes`、`note_tags`、`tag_meta`、FTS5 trigram 全文索引 `notes_fts`）。
  旧版 `annotations/*.json` 会在首次启动时自动导入。
- `reader.db` 里还有待办与目标（`tasks`、`goals`、`task_goals`）、阅读时长（`reading_days`）、目标进度快照（`goal_snaps`）、笔记回顾（`review_items`、`review_log`）和回收站（`trash`）
- `book_text.db`：书中文字索引，可重建、不进备份（见「书中文字搜索」）
- 设置环境变量 `READER_DATA_DIR` 可改用其他数据目录（自动化测试用）

## 界面语言

支持简体中文、繁體中文（台湾用语）、English，在「设置 → 外观与阅读 → 语言」选择，默认跟随系统。界面文字都在 `src/i18n/`（简体为源语言，其余必须有相同的键）。写进笔记的约定文字（待办的 `截止:` / `due:`、优先级、复盘标签等）按当前语言写入，但解析时三种写法都认，已有笔记不会被改写。Rust 端返回的中文错误提示由前端按文字匹配翻译（`src/i18n/errors.ts`）。新增文字时运行 `node scripts/check-i18n.mjs`（加 `--list` 看还有哪些中文写在词典之外）。

## 阅读时长与周回顾

读书时自动记录真正在读的时间（窗口在前面、有焦点、最近 60/90/180 秒内有操作才计时，设置里可改或关闭），按“天 × 书”存在本机数据库的 `reading_days` 表里。每本书的阅读面板里看累计时长、天数、速度、预计读完日；书架顶部是阅读热力图。任务页侧栏的“周回顾”汇总这一周的阅读、笔记（挑最值得重读的）、待办与目标，页底写三句话，存成一条带标签的随手记（标签默认 `#Lifelog/WeeklyReview`，可在设置里改），“下周先做哪一件”直接成为下周的待办。

## 笔记回顾（间隔重读）

笔记页侧栏的「笔记回顾」按遗忘规律安排每天该重读哪几条笔记（旧的随机读几条保留为页面底部的「再随机读几条」）。

- **哪些笔记会进来**：所有有内容的笔记（含只划线没写想法的）；带排除标签的不进，默认排除 `Status/待办复盘` 和周回顾标签。新写的笔记第二天第一次出现。
- **怎么读**：一次一条，读完选「忘了 / 模糊 / 记得」（键盘 1 / 2 / 3，按钮下写着选了之后几天再见）。「记得」升一级，「模糊」原地，「忘了」退两级；间隔依次约 1 / 3 / 7 / 14 / 30 / 60 / 120 / 240 天，带 ±10% 的错开，避免一天扎堆。还可以「明天再看」或「不再回顾」。
- **每天几条**：设置 → 通用 → 笔记回顾里选 3 / 5 / 10 / 20 / 不限（默认 5），超出的顺延；还能设排除标签、「新的一天从几点开始」（默认凌晨 4 点）、一键重置进度。
- **别处也能看到**：笔记页侧栏有今天还剩几条的角标；桌面笔记卡片有待回顾的笔记时只显示它，下面是三个评分按钮；周回顾里有一行「回顾了 N 条，记得 X%」；Markdown 备份末尾有「笔记回顾记录」。
- **数据**：`reader.db` 的 `review_items`（每条笔记的进度）和 `review_log`（每天的作答）。删除笔记时进度一起进回收站，恢复时一并恢复。

## 标签主题

每个标签自成一页，把它的笔记、书、待办和目标合在一起看。

- **入口**：笔记页侧栏「标签」标题右边的「标签主题」是总览（每个顶级标签一张卡片，显示笔记数、待办数、进度条和子标签，可搜索、按数量或名称排序）；也可以在侧栏选中一个标签后点列表上方的「打开主题页」，或在 Ctrl+K 里输入 `#标签` 回车。
- **页面内容**：范围条（「包含子标签」开关和子标签 chip，点 chip 进入子主题）、相关的书、待办（带进度条，可直接勾选完成）、关联的目标（由这些待办所属的目标反推，目标本身没有标签）、笔记（先显示 20 条，可展开更多）。
- 标签别名（不同语言写出的同一标签）按同一个主题合并。

## 命令面板与快捷键

**Ctrl+K** 在任何页面打开命令面板（Spotlight 风格的浮层，Esc 或点遮罩关闭）：

- 输入后按类型分组：标签、书和文章、笔记（数据库全文搜索）、待办、目标、命令，最后一组是「书中文字」。刚打开时显示最近用过的条目和常用命令；什么都搜不到时可以直接把搜索词记成一条随手记。
- 前缀缩小范围：`#` 只搜标签，`@` 只搜书和文章，`/` 只搜命令，`~` 只搜书中文字；输入栏为空时按 Backspace 退出前缀。
- 命令包括：新建随手记 / 待办、导入文档、保存网页文章、跳转到各页面（笔记、书架、任务、探索）和各视图（笔记回顾、标签主题、回收站、各待办列表、本月 / 年度目标、周回顾）、打开设置的各页签、切换深色 / 浅色主题、切换语言、显示 / 隐藏桌面卡片。

**快捷键**可在「设置 → 快捷键」里查看和修改，点右侧的框再按新的组合键（Esc 取消、Backspace 清除；必须带 Ctrl、Alt 或 Shift，功能键除外；与别的命令重复时会问是否改给当前命令；复制粘贴等保留键不能用）。只保存改过的，默认值如下，只在墨边窗口处于前台时生效：

| 命令 | 默认键 | 命令 | 默认键 |
|---|---|---|---|
| 命令面板 | Ctrl+K | 笔记回顾 | Alt+R |
| 新建随手记 | Ctrl+N | 标签主题 | Alt+T |
| 新建待办 | Ctrl+Shift+N | 今天的待办 | Alt+D |
| 导入文档 | Ctrl+O | 打开设置 | Ctrl+, |
| 笔记 / 书架 / 任务 / 探索 | Alt+1 / 2 / 3 / 4 | 切换深浅主题 | Ctrl+Shift+D |

**Ctrl+N / Ctrl+Shift+N** 在当前页面上弹出一个小窗口（里面就是笔记页的输入框 / 任务页的快速添加），不跳页、不打断阅读；Ctrl+Enter（待办是 Enter）保存后窗口关闭，Esc 取消，每次打开都是空的。如果当前页面本来就有这个输入框（笔记页、任务页），则直接清空并聚焦那个框，不再弹窗。

## 书中文字搜索

书架上的书和文章的**正文**可以搜索（笔记本来就能搜）。支持 EPUB、PDF、Markdown、TXT、HTML。

- **建立索引**：后台进行，书架有变动（导入、删除）几秒后自动同步，一次只读一本，读不了的书会跳过。「设置 → 通用 → 书中文字搜索」里能看到进度、占用空间，可以关闭或重建。PDF 读的是文字层，扫描版（只有图片）没有文字，开头 20 页几乎没有文字就直接跳过，设置里会提示有几本是扫描版。
- **索引放在单独的文件**：`book_text.db`（FTS5 三字索引），可以随时重建，不进备份，打不开时自动重新开始；删书时同步删除它的索引。
- **从哪里搜**：Ctrl+K 里的「书中文字」分组（或 `~` 前缀），以及书架页搜索框下方的结果面板，每条显示命中的那一句、书名和章节（PDF 是页码），点一下打开那本书。两个字以上才搜；多个词当作一整句来匹配，大小写不分，行尾换行和 CJK 字之间的空格不影响。
- **在阅读界面里**：打开后滚到命中的位置，把这本书里**所有**命中的地方同时用红色细框框出来，你点进来的那一处用粗框并闪动三次。点正文或按 Esc 收起框。这本书有两处以上命中时，右侧自动出现「搜索结果」面板，按章节分组列出每一处，点哪条跳到哪条，F3 / Shift+F3 或上下按钮逐处切换。PDF 的页面是滚到才绘制的，所以框和面板里的位置随页面出现而补上。
- **限制**：每本书最多框 1500 处，面板最多列 200 段；一句话刚好被切在两段索引之间时整句搜不到；图片里的文字搜不到。

## 回收站与删除确认

笔记和待办删除后先进回收站，保留 30 天，之后彻底删除（启动时和之后每 6 小时检查一次）。

- **确认**：删除前弹出「移到回收站？30 天内可以恢复」，勾上「以后不再询问」后只在窗口下方轻提示一下（约 2 秒，带「撤销」）。笔记和待办共用「设置 → 通用 → 删除」里的开关，随时能重新打开。
- **回收站页面**：笔记页和任务页的侧栏各有一个「回收站」，显示删除时间和还剩几天，可恢复、彻底删除、多选、清空；命令面板里也有入口。
- **恢复**：笔记连同它的关系线、回顾进度、由它转出的待办一起回来；待办连同子任务和目标关联一起回来，来自笔记的待办会把那一行放回笔记原来的位置。上级任务或原笔记已不存在时，恢复成独立的任务。
- **数据**：回收站在 `reader.db` 的 `trash` 表里（每条一份 JSON 快照），其他查询、搜索、统计都看不到回收站里的内容。移除书和文章、删除目标不经过回收站。

## 其他界面细节

- 书架顶部「继续阅读」列出最近打开的 3 本书或文章，点一行直接打开。
- 桌面待办卡片上，落后于时间的目标的百分比显示红色，不落后的保持正常颜色。判断「落后」时，时间从目标创建的那天算起，月中新建的目标不会一建好就被标红（任务页的目标页和周回顾用同一规则）。
- 页面空白处的右键不再弹浏览器自带菜单；输入框、笔记编辑区和选中了文字的地方保留系统菜单（复制、粘贴等）；按住 Shift 再右键始终显示，方便调试。
- 「设置 → 通用」按功能分成独立的卡片：阅读记录、周回顾、笔记回顾、书中文字搜索、删除（桌面版还有桌面卡片与开机启动）。

## 路线图

- v0.2：订阅 P2（无 RSS 网站的站点地图/列表页识别、预览面板、键盘快捷键、批量处理）；需要登录站点的浏览器扩展；标签拼音补全
- v0.3：笔记导出到 PDF 原生注释、Obsidian 链接、自定义主题
- v0.4：移动端交互打磨，WebDAV 同步
- **桌面卡片**（v0.4 已做）：托盘图标、关闭主窗口时隐藏到托盘（有卡片显示时）、开机自启、两张桌面卡片（笔记：小方块与每日回顾；待办：本月目标、今日与明日待办），可拖动、缩放、置顶、调透明度，点击条目回到主界面对应位置。仍可做：压到桌面图标层、更多卡片种类、Mac 版（需另写 WidgetKit）
- **大规模数据性能优化**（计划下个版本做；目标：几万条笔记、上万条待办、上千本书仍然流畅）。现状：笔记在 SQLite 里（全文索引、列表分页取 100 条），几千条没问题，一万条大体可用；以下是随规模变慢的地方，按优先级：
  1. **笔记回顾每 10 分钟“取全部笔记”补排期**（`src/review/engine.ts` 的 `ensureReviewItems`）→ 改成只查“还没有排期的笔记”（Rust 里 `notes LEFT JOIN review_items`），或只处理新增和修改过的。
  2. **待办整体读进内存、前端筛选**（`src/tasks/store.ts`）；每次保存笔记还要把全部待办对一遍（`syncTasksFor`）→ 待办按笔记分组取、列表分页；筛选下沉到 Rust。
  3. **其他“取全部”**：周回顾、Markdown 备份、重新同步待办标签、标签主题页（`limit: -1`）→ 周回顾已按日期范围取，其余改成分批或流式；备份分块写。
  4. **书架是一个 JSON 文件，每次改动整份重写**（`loadLibrary` / `saveLibrary`）→ 书的元数据进 SQLite，按需读写；上千本时书架列表也要虚拟滚动。
  5. **两个字的短搜索走全表扫描**（全文索引需要 3 个字以上）→ 评估 2 字用前缀/bigram 索引，或限制扫描范围并给出提示。
  6. **长列表渲染**：笔记列表、待办列表、标签主题页的笔记区 → 虚拟滚动，一次只渲染看得见的行。
  7. **回收站**：条目多时 `trash_all` 一次读全部 → 按类型分页。
  - **图片部分**（按 2 万条笔记、其中 20% 带图，约 4000 条、估计 1.5~7GB 来算，图片会比文字先出问题）。现状：图片是磁盘上的单个文件，加载时由 Rust 转成 base64 整张传给页面（`image_get`）；列表里的缩略图用的也是最长边可达 2000 像素的原图；加载过的图放进不限量的缓存（`src/notes/images.ts` 的 `cache`），滚动浏览时内存会一直涨；图片文件从不清理；备份、导出要处理全部图片。改进，按收益排序：
    1. **缩略图**：保存图片时同时生成约 400 像素的小图（多占约 5%~10% 空间），列表只用小图，点开才读原图；已有图片在后台慢慢补生成。
    2. **改走文件地址，不再 base64 传输**：用 Tauri 的资源协议让图片直接从磁盘按地址加载，缓存和释放交给浏览器内核。最省内存，但牵涉权限配置，必须先在桌面窗口里小范围实测，确认安装版也能显示。
    3. **只加载看得见的图**：滚到附近才请求，配合列表虚拟滚动。
    4. **缓存加上限**：只留最近用过的几十张。
    5. **清理未被引用的图片**：在每天的回收站清理里顺带处理，既不属于笔记、也不在回收站里的图才删；设置里显示图片占用的空间。
    6. **备份和导出增量复制**：已复制且未变的图片跳过。
  - 建议顺序：先做图片的 1~4（体感改善最大，也是 4000 张图场景下避免卡死的关键），再做上面的 1、2（笔记回顾和待办的加载），最后做图片的 5、6。
  - 验证：`notes.rs` 里已有一个默认忽略的基准测试，生成 2 万条笔记并计时（分页、标签筛选、全文搜索、短搜索、标签树、取全部）：`cargo test --release scale_notes -- --ignored --nocapture`，用环境变量 `SCALE_N` 改条数；优化前后各跑一次对比。待办、书架还没有对应的基准，需要补。
- **华为 EMUI / Android 版**（已规划，暂缓）：Tauri 2 Android 打包，分 A 打通 → B 兼容（华为 WebView 偏旧：审计 `color-mix`、`:has()`、pdf.js 新语法，降低构建目标，PDF 用 legacy 版）→ C 能用（content:// 文件导入、返回键、选字工具条）→ D 联网（订阅、剪藏、接收系统分享）→ E 发布（签名 APK）。注意：HarmonyOS NEXT 不兼容 Android 应用。本机已有 Android Studio / SDK，缺 NDK 与 Rust Android target
